Edit long talks and podcasts: clean the sound, sync a separate recorder with the video, edit by deleting words in the transcript, and make Reels. Your big video file never leaves your computer — the final 4K video is made on your computer by the free tool ffmpeg, using the files this page gives you.

A full-screen editing room laid out like DaVinci Resolve: timeline, viewer, and Media · Edit · Color · Fairlight · Deliver pages. Same project as the steps below.
Install ffmpeg (once, about 5 minutes)
Windows: click Start, type cmd, open Command Prompt, paste winget install Gyan.FFmpeg and press Enter. Close and reopen any open windows afterwards.
Mac: open Terminal and paste /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)", press Enter and follow it; then paste brew install ffmpeg.
Check: type ffmpeg -version — it should print a version number.
Studio Engine — the heavy work, done on this computer

Studio Engine: not connected.

The free Studio Engine runs on your own computer: it checks your files, cleans the sound with AI voice isolation, syncs and makes the final videos — with live progress, and it can pause and continue. Nothing is uploaded. Without it, the download-a-script steps below still work.

Install the Studio Engine (once, 5–15 minutes)
Windows: right-click the Start button → Terminal (or Windows PowerShell). Copy this line, paste it into that window and press Enter:
irm https://raw.githubusercontent.com/rpingclaw-cmd/PSM/main/engine/install.ps1 | iex
Mac: open Terminal, paste this line and press Return:
curl -fsSL https://raw.githubusercontent.com/rpingclaw-cmd/PSM/main/engine/install.sh | bash
When it finishes, this page opens by itself and shows Engine connected ✓. If the browser asks to access other apps and services on this device, click Allow.
Next time: double-click Start Studio Engine on your desktop. To update the engine, run the same line again.

        AI key (free)
        
Finding quotes and transcribing audio use Google Gemini. Get a free key at aistudio.google.com (Get API key) and paste it here. It is kept only in this browser. On Google's free tier, what you send may be used to improve Google's products — fine for published books and public talks.

        
        
        

      

      

        Backup AI keys (free)
        
When Gemini hits its free limit, the app automatically switches to the next key here and carries on. Big books are read in parts sized for each service. Mistral has the most generous free tier for books; Groq (with a q) adds free, fast audio transcription. Keys stay in this browser.
